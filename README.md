A modern, fast, and responsive engineering portfolio showcasing 8+ years of software architecture, featured projects, impact benchmarks, and live client contact integration.

---

## 🌟 Features

- **⚡ Interactive Project Pipeline:** Filter and explore production systems across .NET & C#, Mobile (Flutter & Android), Full-Stack, and AI.
- **📊 Impact Metrics Counter:** Verified benchmarks detailing SLA uptime, latency thresholds (<60ms), and team leadership.
- **✉️ Direct Client Dispatch:** Integrated EmailJS pipeline with validation, status toasts, and quick clipboard backup.
- **📄 Live Resume Viewer:** Built-in downloadable CV preview with tabbed experience details.
- **🎨 Modular SCSS:** Custom typography, animated letter transitions, smooth route navigation, and dark aesthetics.

---

## 🛠️ Tech Stack

- **Frontend:** React 18, React Router v6
- **Styling:** Modular SCSS, Animate.css, FontAwesome icons
- **Integrations:** EmailJS Browser SDK, Leaflet / Mapbox embed
- **Deployment & CI/CD:** GitHub Pages (`gh-pages`)

---

## 🚀 Local Development Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/HasanCSE-IYI/portfolio-one.git
   cd portfolio-one
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm start
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
